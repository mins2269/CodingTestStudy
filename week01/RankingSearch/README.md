# [프로그래머스 72412] 순위 검색

- 링크: https://school.programmers.co.kr/learn/courses/30/lessons/72412
- 난이도: Lv.2
- 유형: 해시맵, 이진 탐색

## 문제 요약
지원자 정보와 조건 쿼리가 주어질 때, 조건을 만족하는 지원자 수를 구한다.

## 내 풀이 (Solution.java)
- 접근 방법
  - info를 split(" ")으로 잘라 2차원 배열에 저장
  - 쿼리마다 " and "를 제거해 5개 조건으로 분리
  - 하나의 쿼리가 2차원 info 배열의 프로그래밍 언어를 검사하여 1차 후보를 모으고, 
  직군 -> 경력 -> 소울푸드 -> 점수 순으로 removeif로 걸러냄
  - 남은 후보 수가 하나의 쿼리의 답이 된다.
- 시간복잡도
  - **O(Q × N)** → 쿼리마다 info 전체를 순회하며 조건별 removeif로 필터링

## 더 나은 풀이 (BetterSolution.java)
- 개선점: 쿼리가 오기 전에, 가능한 모든 질문의 답을 미리 정해둔다.
- 접근 방법
  - 1단계 전처리, 지원자마다 16개 키 만들기
    - 4 x 4 -> 언어, 직군, 경력, 소울푸드, 총 4개
    - key = "언어, 직군, 경력, 소울푸드"의 조합
  - 2단계: 점수 목록 오름차순 정렬
    - 이진 탐색을 사용하기 위해
  - 3단계: 쿼리 처리, 키 변환 + 이진탐색
    - 쿼리를 "언어, 직군, 경력, 소울푸드 / 점수"로 나누어 map에 저장한다.
    - 쿼리의 key 값을 추출하고 map.get(key)를 호출하면 쿼리와 같은 key값을 갇는 지원자들의
    정렬된 점수 list를 받을 수 있다.
    - 이진탐색을 통해 쿼리의 점수 바로 아래 점수를 잘라내어 size를 알아낼 수 있다.
- 시간 복잡도
  - **O(16N + Q log N)**
